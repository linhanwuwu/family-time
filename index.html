【1】怎么启动（重点，先看这条）

双击文件夹里的「启动游戏_DX12.bat」就行。

如果系统弹窗或者杀毒软件拦截，选「允许运行」。

如果不想用 bat，也可以自己建快捷方式：右键 FamilyTime.exe → 创建快捷方式 → 右键这个快捷方式 → 属性 → 在「目标」那一栏的最后面，空一格，加上：

-force-d3d12
★ 千万不要直接双击 FamilyTime.exe！

【2】为什么必须加 -force-d3d12

这个游戏用 Unity 的 DirectX 12 渲染，画面核心部分全靠 DX12 的显卡计算能力跑。但 Unity 有一条"保守"的默认规则：如果它认为你的显卡（尤其是 AMD / Intel 的集成显卡）不该用 DX12，就会自动降级成 DX11。

降级之后，画面的核心模块全部加载失败，结果就是：

能听到声音，但画面全黑，鼠标点哪里都没反应。

加 -force-d3d12 就是强制它走 DX12，绕过这个自动降级。用独立显卡的机器加了这个参数也没有副作用，放心用。

【3】黑屏 / 进不去 / 卡 自查顺序（按顺序来）

  1. 确认你是用「启动游戏_DX12.bat」或带 -force-d3d12 的快捷方式启动的 —— 九成的黑屏就是这个原因。
  2. 黑屏出现后，按一下 Alt + Enter，看画面能不能出来。
  3. 右键 FamilyTime.exe → 属性 → 兼容性 → 勾选「关闭全屏优化」和「以管理员身份运行」，再启动一次。
  4. 关掉会"盖"在游戏上面的软件：Discord、Xbox Game Bar、GeForce Experience、各种加速器的悬浮窗。
  5. 把显卡驱动更新到官网最新版（NVIDIA / AMD / Intel 官网下载，别用第三方驱动工具）。
  6. 笔记本玩家如果卡：Windows 设置 → 系统 → 显示 → 图形 → 添加 FamilyTime.exe → 选「高性能」，让它用独立显卡跑。
  7. 还是卡（这游戏场景里角色很多）：把画质调到最低，分辨率降到 1920×1080 或更低。

【4】还搞不定？让 AI 帮你治（推荐这么干）

AI（豆包、DeepSeek、ChatGPT 等）排查游戏问题很好用，但它必须先知道你的具体情况，才能对症下药。所以先花 2 分钟准备两样东西：

第 1 步　拿到游戏日志

用「启动游戏_DX12.bat」启动过一次之后，游戏文件夹里（和 FamilyTime.exe 同一层）会自动生成一个 PlayerLog.txt，这就是日志。里面写清楚了你的显卡型号、驱动版本、渲染走的是 DX11 还是 DX12、具体卡在哪一步。

第 2 步　拿到电脑配置

按 Win + R，输入 dxdiag 回车 → 弹出的窗口里点「保存所有信息」→ 会得到一个 DxDiag.txt。

第 3 步　把下面这段复制给 AI，并把上面两个文件一起拖进对话框

我在运行独立游戏 Family Time（Unity 引擎，DX12 版本）时出了问题，请帮我排查。

我的现象：黑屏但有声音 / 进不去 / 闪退 / 卡顿     ←（只留符合你的那种）
我已经试过：用 -force-d3d12 启动、Alt+Enter、关掉覆盖层、更新显卡驱动     ←（只留你试过的）
附件是我的游戏日志 PlayerLog.txt 和电脑配置 DxDiag.txt。

请告诉我最可能的原因，并给出具体到"点哪个按钮"的解决步骤。

把日志和配置一起给它，它就能像"看着你的电脑"一样判断，而不是瞎猜着让你重装。

【5】存档说明

· 不同章节的存档不互通。每个章节的存档都是独立的，把 Ep3 的存档放进 Ep4 的存档目录（或反过来）会丢失季节进度和部分内容，导致游戏直接报错。

· 想玩另一章，请从该章节自己的存档目录开始，不要覆盖、不要搬运。

· 存档前建议先备份一份，更新版本后如果异常，可以直接还原。
